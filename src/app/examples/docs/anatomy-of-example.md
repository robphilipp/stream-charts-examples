### anatomy of an example chart

<figure>
    <img src="./public/images/intro-example-parts.png" alt="Anatomy of an Example Chart">
    <figcaption>
        <b>Figure 1</b> The anatomy of an example chart. The "Tabs" provide this page and a page that holds an example for each chart type available in the library. The "Control bar" has controls that provide common features of each chart type and features that are specific to each chart type. The "Tabs" and "Control bar" are part of the example application and are not distributed in the library. The "Chart" holds an example chart – in this case a "Scatter" chart. The "Chart" is an example of a chart type that is provided in the [stream-charts](https://www.npmjs.com/package/stream-charts) library.
    </figcaption>
</figure>

Each example provides a control bar at the top and then the example chart on the bottom. The control bar allows you to select various features of the library – such as filtering, tooltips, markers, trackers, or a legend – and features specific to each chart type.
